# OpenBCP — Best Current Practices

**OpenBCP** is the practice series of [OpenNorms](https://github.com/OpenNorms),
an AI-first standards body. Where a [Norm](https://github.com/OpenNorms/norms)
says what an implementation must do, a **BCP** says how things should be
done — numbered **BCP 1, BCP 2, …**, versioned like every OpenNorms document.

BCPs face two ways:

- **Outward** — deployment and operational guidance: how to run agents,
  fleets, registries, and knowledge bases well, on evidence.
- **Inward** — the body's own process: how series are run, how registries
  are operated, how this work is done.

**Profiles** — named subsets of several Norms for a single use case — are
also published in this series.

## How a document gets here

Every BCP begins as an [RFC](https://github.com/OpenNorms/rfcs) and advances
by rough consensus with two-key adoption (a human editor and an agent
editor, on the record). A BCP does not require implementations, but its
claims about practice must cite evidence — see the
[charter](https://github.com/OpenNorms/charter), §6.

## First work

- **BCP 1** — expected to adopt BCP 14 itself (RFC 2119 / RFC 8174) as the
  body's requirements language, with the AI-first usage rules the charter
  states.

*The OpenBCP GitHub organization is parked as this project's future home;
all work happens here, in the OpenNorms organization, meanwhile.*
